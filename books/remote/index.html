## Notes

Fried and DHH wrote this in 2013 and the pandemic made it
look prophetic. The core argument still holds: the office
is a place people go to get interrupted, and real work
happens in long uninterrupted stretches.

The trust point is the one managers keep dodging. If you
need to watch people work, you have a hiring problem, not
a location problem. Remote just exposes it.

Running a distributed studio, the practices that stuck:

1. Async by default — write it down, decide in threads
2. Overlap hours — a few shared hours beat full calendars
3. Judge output, not presence — the work is the evidence
4. Hire everywhere — local-only hiring shrinks your pool

It's a manifesto, so it oversells. Some work really is
better in a room. But the burden of proof flipped, and
this book flipped it early.
