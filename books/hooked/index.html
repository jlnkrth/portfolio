## Notes

The Hook Model is four steps: trigger, action, variable
reward, investment. Once you see the loop you can't unsee
it — every product I audit now gets mapped against it.

The variable reward chapter is the sharpest. Predictable
rewards get boring; slot-machine variability is what keeps
people pulling. It's also where the ethics get murky, and
Eyal only half-engages with that.

The investment step is underrated. Every bit of data,
content, or setup a user puts in makes the product harder
to leave. Good onboarding isn't about showing features —
it's about getting the user to invest early.

I use this two ways: to design honest habit loops for
products that deserve them, and to notice when an app is
running the loop on me. The manipulation matrix — would
you use it, does it materially improve lives — is a decent
gut check before you build any of this.
