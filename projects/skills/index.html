/ seo-site-audit

One-shot technical SEO audit of an entire website. Sitemap-driven, runs a full check catalog (crawlability, links, markup, structured data, performance, security headers, i18n, mobile, accessibility, images, and AI readiness — and produces a self-contained HTML report with category scores and prioritized fix batches.

Needs nothing but HTTP access. Uses Firecrawl, Google Search Console, and PageSpeed Insights when you have them.

How it works

  1. Onboarding. First run asks which optional tools you have and saves answers to audit-config.json. Nothing is required — every check falls back to plain HTTP.
  2. Inventory. Reads robots.txt and sitemaps to build the full URL list. Sites beyond ~150 pages are declined honestly rather than sampled silently.
  3. Checks. Every page gets every applicable check from the catalog. Results carry confidence labels so a proxy result is never dressed up as definitive.
  4. Report. One self-contained HTML file: summary, category scores, fix batches ordered by priority, what already works, and the full audited-pages table.

Install

Add the skill pack to your agent environment:

npx skills@latest add jlnkrth/skills

Then ask your agent for a technical SEO audit of a site. Optional rungs (Firecrawl, GSC, PageSpeed) upgrade specific checks when available.
