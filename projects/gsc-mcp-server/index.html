/ gsc-mcp-server

MCP server for Google Search Console. Query search performance, list properties, inspect URLs, and list sitemaps from Cursor, Claude Desktop, or any MCP-compatible client.

npx -y @jlnkrth/gsc-mcp-server
npm GitHub

Tools

Tool What it does
gsc_list_sites List Search Console properties for your Google account
gsc_search_analytics Query clicks, impressions, CTR, and position with filters
gsc_inspect_url Inspect index status, crawl state, and mobile usability
gsc_list_sitemaps List submitted sitemaps with status and errors

Quick start

Use the scoped package @jlnkrth/gsc-mcp-server. Set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET before auth.

Situation Auth Run
Cloned repo npm run auth npm start
From npm npx -y -p @jlnkrth/gsc-mcp-server gsc-mcp-auth npx -y @jlnkrth/gsc-mcp-server

Google Cloud setup

  1. Create or select a project in Google Cloud Console.
  2. Enable the Google Search Console API.
  3. Configure the OAuth consent screen (add yourself as a test user if in Testing mode).
  4. Create an OAuth client ID — application type Desktop app.
  5. Add redirect URI http://localhost:3336/callback if prompted.
  6. Copy the Client ID and Client secret.

Authenticate

export GOOGLE_CLIENT_ID="your-client-id.apps.googleusercontent.com"
export GOOGLE_CLIENT_SECRET="your-client-secret"

npx -y -p @jlnkrth/gsc-mcp-server gsc-mcp-auth

Auth opens a browser on port 3336. Tokens save to ~/.config/gsc-mcp/tokens.json by default.

Cursor config

Add to ~/.cursor/mcp.json (merge with existing servers):

{
  "mcpServers": {
    "google-search-console": {
      "command": "npx",
      "args": ["-y", "@jlnkrth/gsc-mcp-server"],
      "env": {
        "GOOGLE_CLIENT_ID": "YOUR_CLIENT_ID",
        "GOOGLE_CLIENT_SECRET": "YOUR_CLIENT_SECRET",
        "GSC_TOKEN_PATH": "/Users/you/.config/gsc-mcp/tokens.json"
      }
    }
  }
}

Keep mcp.json private — it contains your OAuth client secret. Fully quit and restart Cursor after changing MCP config.
